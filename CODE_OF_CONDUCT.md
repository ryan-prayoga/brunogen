# Code of Conduct

## Our Pledge

We want Brunogen to be a practical, welcoming open-source project for API, documentation, and developer-tooling work.

Participants are expected to be respectful, constructive, and focused on improving the project.

## Expected Behavior

- Use welcoming and inclusive language
- Respect different experience levels and backgrounds
- Give actionable feedback
- Keep discussions focused on the technical issue
- Report security-sensitive details responsibly

## Unacceptable Behavior

- Harassment, insults, or personal attacks
- Publishing private information without permission
- Spam or repeated off-topic comments
- Publicly posting secrets, exploit details, or private source code

## Enforcement

The maintainer may edit, hide, or remove comments, issues, pull requests, or other contributions that violate this code of conduct. Repeat or severe violations may result in a ban from the project.

## Attribution

This code of conduct is adapted from common open-source community guidelines and simplified for a small maintainer-led project.
